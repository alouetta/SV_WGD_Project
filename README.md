# SV_WGD_Project

This github repository contains code, instructions and some of the data relating to the Masters Project "Role of Structural Variants in the Adaptation of Arabidopsis arenosa to Whole Genome Duplicatiom". 

There is a folder for each analysis e.g. PCA, Entropy etc. containing scripts, input data where possible and a document with instructions. Where the report for this project refers to supplementary information the information will be in this repository. The original data is not stored here as the files are too large but can be accessed via the HPC.

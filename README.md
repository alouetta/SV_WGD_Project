# SV_WGD_Project

This github repository contains code, instructions and some of the data relating to the Masters Project "Role of Structural Variants in the Adaptation of Arabidopsis arenosa to Whole Genome Duplicatiom". 

There is a folder for each analysis e.g. PCA, Entropy etc. containing scripts, input data where possible and a document with instructions. Where the report for this project refers to supplementary information the information will be in this repository. There is a guide to where supplementary information can be found on page 38 of the report. The original data is not stored here as the files are too large but can be accessed via the HPC.

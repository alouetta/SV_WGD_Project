# SV_WGD_Project

This github repository contains code, instructions and some of the data relating to the Masters Project "Role of Structural Variants in the Adaptation of Arabidopsis arenosa to Whole Genome Duplicatiom". It accompanies the final report, where the report refers to supplementary information the information will be in this repository. The original data is not stored here as the files are too large but can be accessed via the HPC.
